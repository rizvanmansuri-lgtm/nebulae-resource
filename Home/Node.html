Nebulink Node

Introduction

NebuLink Node is a broad-level component of Nebulae that provides wired and wireless connectivity for sensors and other types of equipment. It is pre-programmed with Nebulae to easily deploy Wireless Sensor Networks in dense and large areas with scalability and minimum maintenance costs. The Nebulae architecture protects and recovers data against network dereliction or runtime failure.

NebuLink Nodes comes with a feature-rich IoT SDK that enables developers to create IoT solutions with ease.

Architecture

  • 1. Provides user to configure the SDK to run/add new features/libraries with minimal changes, allows business logic implementation and computing at node.
  • 2. Supports remote FOTA update with secure, robust, reliable, atomic, fail-safe operations.
  • 3. Includes unifies IoT network connectivity support from various wired/wireless: includes 6LoWPAN, Zigbee, G3-PLC, WiFi.
  • 4. Rich Hardware abstraction layer to support any sensor.
  • 5. Rich interface for sensor and I/O control: SPI, UART, I2C, GPIO, ADC.
  • 6. Sensor Interface UART/SP/I2C.

Our Features

Scalability

SDK embedded NebuLink Node imparts high scalability with maximum data transfer, optimum maintenance costs, and minimum human effort.

Interoperability

By managing all communication across connected devices NebuLink Node provides device interoperability and data consistency.

Small footprint and low power

NebuLink Nodes have a tiny footprint and ultra-low-power consumption designed to simplify network connectivity integration into product designs.

Security

Using 128 bit AES, NebuLink Node provides end-to-end secured communication over a pair of public and private keys to delivering confidentiality, integrity, and authentication.
