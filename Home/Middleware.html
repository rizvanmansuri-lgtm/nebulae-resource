Nebulink Middleware

Introduction

NebuLink Middleware, a mediator between the hardware i.e internet-connected devices and user applications, integrates nodes such as sensors and gateways with the applications using middleware super agent thus allows to connect, operate and automate IoT devices via a single platform.

NebuLink Middleware is acting as a backbone platform, provides all functionality that required to operate mission-critical IoT applications with large scalability, failure proof connectivity, device interoperability, data consistency, and security by managing all communication across connected devices. It also supports device Firmware over the air, Remote management, health monitoring, Alert Notifications and device management services.

Our Features

Secure Firmware Update

With 3 layer verification and PKI (Public Key Infrastructure) based security features, FOTA(FirmwareUpdate Over The Air) offers a robust, reliable, and fail-safe mechanism to ward off any threats to a system. FOTA also provides group firmware update for similar devices.

Data collection and Analytics

Enable you not only to monitor topic wise live data and communication logs emanating from the endpoints to NebuLink Middleware but also, provide secure API's to get any particular endpoints raw history data with and without time range.

Device Management

Use device dashboard to register and monitor device status, live data with topic,send topic wise notifications, control your device, get history of communication logs.

Security

NebuLink Middleware uses a hybrid encryption system based on RSA with a 2048-bit key pair and AES with a 256-bit key to authenticate devices in the network. It also supports SSL/TLS secure communication over the network.

Device Remote Management

NebuLink Middleware enables you to securely access and execute commands in your deployed device remotely regardless of the network environment. It is useful for real-time control during running production.

Scalability

With the inbuilt design, NebuLink Middleware imparts high scalability enabling you to add more servers to the middleware cluster to reliably support myriads endpoints with maximum data transfer and optimum maintenance costs.

Supported Platforms

Middleware Super Agent supports the Linux platforms. It can be downloaded for mentioned Linux ports: x86_64, ARMel, ARMhf and ARM64.

Device Health Monitoring

Continuously monitor the deployed device's uptime, memory usage, CPU usage and number of applications running in same.
