Nebulink Gateway

Introduction

NebuLink IoT Gateway offers rich out-of-the-box functionality and versatile connectivity options, suitable for a wide range of applications from Smart Home to Industry 4.0. The advance peripheral mechanism provides configuration and access control from a remote location using NebuLink Cloud services to integrate with third-party cloud infrastructure.

NebuLink IoT Gateways comes with a feature-rich IoT SDK based on FreeRTOS and LINUX.

Architecture

  • 1. Provides user to configure the SDK (application) to run/ add new feature/ libraries with minimal changes.
  • 2. In built crypto security feature with PKI Certificates (X.509), Message Digest (RSA/SHA256), Encryption (AES-128,256) & Authentication (ECDSA as specified by RFC 6979), Communication over Secure TLS1.2 / SSL with HTTPs/TCP/MQTT
  • 3. Local storage for event, user data, configuration and diagnostics
  • 4. Provides optional local edge computing engine to offload the cloud processing.
  • 5. Inbuild SLS Nebulae Middleware support and other 3rd Party Cloud support using MQTT, REST, WebSocket etc.
  • 6. Supports remote FOTA update with secure, robust, reliable, atomic, fail-safe operations.
  • 7. Provides a remote management agent for service and application life-cycle management.
  • 8. Provides capability to onboard new devices and organizing existing devices in groups in no time.
  • 9. Includes cross industry protocol support ModBUS, CANopen, IEC61850, IEC62056[DLMS], IEC60870-5, OPC-DA, IEC61131-9[IO-Link] etc.
  • 10. Includes unified IoT network connectivity support from various wired/wireless protocols e.g. 6LoWPAN, ZigBee, G3PLC, LoRa, WiFi
  • 11. Available on multiple OS like FreeRTOS and Yocto Linux with customization possible.
  • 12. True Hardware agnostic as it can run from smallest micro-controller to FPGA/SoCs

Our Features

Security

By employing the AES-encrypted TCP-based binary protocol for E2E data, NebuLink Gateway provides additional security and integrity to IoT data, devices, and the entire IoT ecosystem.

Reduced Latency

Our IoT Gateway uses edge computing capabilities to execute heavy data processing before sending data to Middleware hence reducing latency.

Scalability

With inbuilt redundancy and hardware-agnostic characteristics, our Gateway imparts high scalability with maximum data transfer to handle myriads' applications and devices.

Third-Party Integration

The advanced peripheral mechanism provides configuration and remote access control for Gateway to integrate with third-party cloud infrastructure.
