Nebulink FOTA

Introduction

NebuLink FOTA is an essential Nebulae service to protect the IoT eco-system from obsolescence, hacking, and bugs. It can be used or available as a service into NebuLink Milldleware or any 3rd party Middleware running on Node and Gateway. NebuLink FOTA service allows zero-configuration with the shortest downtime with a single reboot on firmware updates.

Our FOTA service is a robust, reliable, and fail-safe mechanism for group firmware update aswell.

Our Features

Security

With 3 layer verification and PKI (Public Key Infrastructure) based security features, NebuLink FOTA offers a robust, reliable, and fail-safe mechanism to ward off any threats to a system.

Group Firmware Updates

By verifying firmware integrity and authentication, NebuLink FOTA provides a Group firmware update for similar devices via Multicast and Broadcast Support.

Accurate FOTA Images

NebuLink FOTA enables the firmware to generate accurate FOTA images as per specifications. It also provides parent and child firmware update support.

Platform Independent

As the FOTA update is platform-independent, it enables you to update applications on any device anywhere and on any platform.

Configurable Chunk Size and Bandwidth Support

Thanks to the chunking mechanism FOTA supports huge data downloads from Enterprise Datasource to devices without interruption on low bandwidth.

Compression Support

A fast dictionary-based compression algorithm for the program code utilizes the copy information stored in the delta without increasing its size, thus providing fast encoding and decoding.

USE CASES

Industrial IoT

Nubulink FOTA remotely updates all functionality in your industrial IoT applications in one go over-the-air. This reduces on-field maintenance costs and data costs with minimum system downtime.

Smart Infrastructure

NebuLink FOTA protects strategic installations such as nuclear plants, strategic defense installations, fertilizer plants, and bridges from hacking, bugs, Botnets, Man-in-the-Middle concept, and Denial of Service attacks.

Smart Grid

From power generation to transmission and distribution to the final consumer, the NebuLink FOTA update fixes the bug and safeguards your smart grid applications and ecosystem against any possible security vulnerability.

Smart City Applications

The FOTA update enables the urban planner to insert specific functionalities such as better device connectivity, reduction in memory, and power consumption into your smart city applications on a large scale with minimum data usage.

Smart Vehicle

By updating firmware on device post-deployment, FOTA update reduces on-field maintenance costs and enables the OEM to remotely fix bugs, address functional faults, update security features and enhance functionality in automotive ECU software of your smart car applications anywhere any time.
